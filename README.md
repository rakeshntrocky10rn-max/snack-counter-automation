
# Snack Counter Automation

A Java-based solution for automating snack counter refills across Oslo and Bengaluru offices.

## Technologies
- Java 11
- Maven
- JUnit 5

## Features
- Refill request management
- Volunteer assignment
- Duplicate claim prevention
- Budget validation
- Receipt tracking
- HR reimbursement simulation
- Expired claim reassignment
- Monthly spending tracking

## How to Run

Run the Main.java class from Eclipse.

## Run Tests

Execute:

mvn test
